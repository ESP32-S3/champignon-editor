⚙️ CONFIGURATION
───────────────────────────────────────────────────────────────────────────────
Edit config.json to customize:
  - fontFamily: Font to use (default: "Champignon")
  - fontSize: Point size (default: 28)
  - fontFeatures: OpenType features to enable
  - theme: Color scheme (default: "dark")
  - tabWidth: Spaces per tab (default: 4)
  - lineHeight: Line spacing (default: 1.6)


🔍 KEY FINDING
───────────────────────────────────────────────────────────────────────────────
Champignon does NOT automatically connect letters through OpenType cursive
features. It is a proportional script font where:
  - Each letter is an independent glyph
  - Letters appear "connected" due to decorative glyph design
  - No cursive attachment tables exist in the font
  - This is the font's design, not a limitation

Result: Each character renders beautifully but independently.

🔧 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

"Module not found: PyQt6"
  → PyQt6 should be pre-installed. Verify with:
    python3 -c "import PyQt6; print('OK')"

"Champignon font not found"
  → Verify fonts are installed:
    fc-list | grep -i champignon

"hb-shape command not found"
  → This is optional. The editor works without it.

"GUI window won't appear"
  → This is a GUI app requiring X11/Wayland display.
  → Cannot run over SSH without X forwarding.
