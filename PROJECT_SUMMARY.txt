💻 INSTALLATION
────────────────────────────────────────────────────────────────────────────
Quick Start (Linux/macOS):
  git clone https://github.com/esp32s3/champignon-editor.git
  cd champignon-editor
  pip install -r requirements.txt
  python champignon_editor.py

Quick Start (Windows):
  git clone https://github.com/esp32s3/champignon-editor.git
  cd champignon-editor
  pip install -r requirements.txt
  python champignon_editor.py

Via pip (once published):
  pip install champignon-editor

Via setup.py:
  pip install -e .

🎯 LAUNCH
────────────────────────────────────────────────────────────────────────────
Option 1:
  cd ~/champignon-editor && ./run_editor.sh

Option 2:

Option 3 (Windows):
  python champignon_editor.py  [or double-click run_editor.sh]

Option 4 (after pip install):
